# AI Agent Email Box Simulation

This Python script simulates an AI agent with its own email inbox. It demonstrates how an agent can receive emails, process them, and send replies, mimicking the core concept of an AI agent interacting via email like a human user.

## Language

`python`

## How to Run

Save the code as `ai_email_agent.py` and run it from your terminal using `python ai_email_agent.py`.
